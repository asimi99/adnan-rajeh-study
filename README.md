# Adnan Rajeh Study (iOS)

Native SwiftUI app for the study site. It reads the same data the website publishes and syncs progress and reflections with the same Supabase account.

## First run
1. Open `AdnanStudy.xcodeproj` in Xcode 16 or newer.
2. Click the project, then the AdnanStudy target, then Signing & Capabilities. Pick your team.
3. Choose an iPhone simulator (or your phone) at the top and press Run.

## Updating
In Xcode: Integrate > Pull. Or in Terminal from this folder: `git pull`.
